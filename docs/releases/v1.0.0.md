# European Tech Opportunities 2027 v1.0.0

[← Documentation home](../README.md) · [Open the directory](https://techopportunities.eu/) · [User guide](../users/README.md)

The first stable release brings together a searchable directory of European technology internships and **New Grad** roles for the 2027 hiring cycle, private browser lists, and open data for spreadsheets, applications, and feed readers.

## Find your next role

Browse by country, company, technology category, or employment type. Search across listings, sort the results, and filter by when roles were first seen. Filters, sorting, and pagination stay in the URL, so you can bookmark a search or share it with someone else.

Each role links to its original LinkedIn listing, where you can check the requirements and apply. The directory favors clear evidence over complete coverage: ambiguous roles are left out, and a listing disappearing from search results does not automatically mark it closed.

**[Explore the directory →](https://techopportunities.eu/)** · [Browsing guide](../users/browsing/directory.md)

## Keep track without an account

Save interesting roles, mark those you have applied to, hide others, and see what is new since your previous visit. Your lists stay in your browser: they are not stored on the server, included in shared links, or synchronized between devices.

The website supports keyboard navigation, visible focus, light and dark themes, and responsive layouts. Browser journeys and axe accessibility checks cover the main browsing and list-management interactions.

## Use the data your way

| Access | What it provides |
|---|---|
| [CSV](https://techopportunities.eu/open-opportunities.csv) | The complete open directory for spreadsheets, with spreadsheet-safe text |
| [JSON](https://techopportunities.eu/open-opportunities.json) | The complete open directory for scripts and analysis |
| [Public API](https://techopportunities.eu/api/v1/opportunities) | Read-only, filtered, sorted, and paginated listings, without an API key |
| [RSS](https://techopportunities.eu/feed.xml) / [Atom](https://techopportunities.eu/atom.xml) | Up to 50 recent open roles, with optional employment-type, country, and category filters |

Downloads include checksum metadata, and the API and datasets share a published JSON Schema. The API also provides a status endpoint for checking the served dataset's freshness. Public API paths and schema identifiers remain `v1`, independently of the application release number.

## Behind the directory

A bounded Python pipeline normalizes public listing information and applies deterministic checks for employment type, seniority, technology, hiring cycle, posting date, and European location. SQLite is the canonical source of listing history, with repository transactions and Alembic migrations preserving provenance and lifecycle state. The website, API, feeds, downloads, and README only read that state.

Collection requires express source permission; it uses no source accounts, private APIs, or anti-bot bypasses. Offline tests, strict typing, schema checks, and CI security analysis cover the pipeline and public interfaces. Unprivileged containers, read-only website data, verified snapshots, atomic dataset publication, and documented rollback support deployment and recovery.
