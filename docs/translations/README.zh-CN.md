## 为什么做这个项目？

在欧洲寻找技术实习或第一份工作，不应该意味着要逐条翻看数百条分散、过时或不相关的招聘信息。

**European Tech Opportunities 2027** 将欧洲各地面向 2027 年招聘季的 **实习岗位** 与 **应届毕业生及初级岗位**（New Grad）汇集在一个可搜索的目录中。每条职位信息均按照项目的收录标准筛选。采集任务计划每三天运行一次。当新职位大量出现或招聘市场出现值得关注的变化时，维护者会手动增加更新频次。目录更新须经审核和验证后才会部署到生产环境。

搜索感兴趣的公司，按国家或技术类别筛选，或者看看最近新增了哪些职位。搜索结果可以直接通过链接分享，无需安装软件或注册账号。**你可以收藏职位、标记已投递的申请、隐藏不感兴趣的岗位，并查看自上次访问以来新增的机会。** 这些记录仅保存在当前浏览器中，不会跨设备同步。标记“已投递”只是帮助你管理求职进度，并不会替你提交申请。

想在网站之外使用这些数据？可以将全部在招职位下载为 **CSV 或 JSON**，也可以通过免费、只读的 **公共 API** 获取。

## 使用数据

无论是制作电子表格、开发个人项目，还是通过订阅阅读器追踪新机会，都可以直接使用这些数据，无需注册账号。

| 获取方式 | 适用场景 | 提供的内容 |
|---|---|---|
| [在线目录](https://techopportunities.eu/) | 浏览与分享 | 搜索、筛选、排序、分页、本地收藏与记录，以及原始招聘链接 |
| [CSV](https://techopportunities.eu/open-opportunities.csv) | 电子表格 | 全部在招职位，文本字段经过处理，避免被电子表格识别为公式 |
| [JSON](https://techopportunities.eu/open-opportunities.json) | 脚本和数据分析 | 以单个数组提供全部在招职位 |
| [公共 API](https://techopportunities.eu/api/v1/opportunities) | 应用和集成 | 支持筛选、排序、分页及缓存的 JSON 数据 |
| [RSS](https://techopportunities.eu/feed.xml) / [Atom](https://techopportunities.eu/atom.xml) | 订阅阅读器 | 最多 50 条近期在招职位，支持按职位类型、国家和技术类别筛选 |

下载文件包含全部在招职位，不限于当前搜索结果。公共 API 仅提供读取功能，无需 API 密钥，支持筛选、排序和分页。

入门说明见 [数据下载指南](../users/data/data.md)、[API 指南](../users/data/api.md) 和 [订阅指南](../users/browsing/directory.md#subscribe-to-new-opportunities)。

## 宁可精准，不求面面俱到

当信息不足以确认职位是否符合条件时，我们宁可暂不收录，也不凭猜测作出判断。同样，某条招聘信息从搜索结果中消失，并不代表该职位已经关闭。

| 检查项 | 判断依据 |
|---|---|
| **职位类型** | 职位标题明确注明实习或 New Grad |
| **资历要求** | 排除标题中包含高级或管理岗位相关用语的职位 |
| **技术领域** | 职位符合项目设定的技术类别 |
| **招聘周期 / 发布日期** | 明确属于 2027 年招聘周期；或未标明其他冲突的招聘周期，且有符合规则的证据证明其发布于 2026 年 5 月 1 日或之后 |
| **欧洲工作地点** | 招聘信息中有明确的欧洲工作地点依据 |

详细规则见 [分类指南](../maintainers/engineering/classification.md)。

## 项目如何运作

1. 在预设的请求数量限制内搜集公开招聘信息。
2. 核对职位类型、资历要求、招聘周期、发布日期和欧洲工作地点。
3. 将符合条件的职位及其历史记录保存到项目的 SQLite 数据库。
4. 通过网站、API、订阅源、数据下载和 README 预览展示在招职位。这些渠道只读取数据，不会修改职位状态，也不负责判断职位是否符合收录标准。

数据采集需要明确授权，并受到固定的请求数量限制。项目不使用 LinkedIn 登录、私有 API，也不绕过反机器人保护措施。想了解内部设计，可以阅读 [架构指南](../maintainers/engineering/architecture.md) 和 [安全政策](../../SECURITY.md)。

## 技术实现

这个简单易用的职位目录背后，是一套开源技术架构。主要技术与实现如下：

| 领域 | 实现 |
|---|---|
| **采集与分类** | Python 3.12+、设有明确上限的异步采集、规范化处理、确定性的收录与排除判断 |
| **数据存储** | SQLite 作为职位状态与生命周期的唯一可信数据源，SQLAlchemy 数据访问层，Alembic 数据库迁移 |
| **Web 应用** | Next.js、React、启用严格模式的 TypeScript、Tailwind，通过 `node:sqlite` 只读访问 |
| **公共数据** | 版本化 API、确定性 CSV/JSON 导出、JSON Schema、含 SHA-256 的数据集元数据 |
| **测试** | Pytest 单元及集成测试、Playwright 浏览器用户流程测试、axe 无障碍检查、属性测试、Lighthouse、解析器与分类器性能基准测试 |
| **安全与 CI** | GitHub Actions、CodeQL、Gitleaks、Dependency Review、OpenSSF Scorecard、容器和文档验证 |

离线测试覆盖职位收录规则、安全的状态更新、浏览器本地列表隐私、无障碍访问、数据下载和故障恢复。测试覆盖率、运行命令及已知限制详见 [测试指南](../maintainers/engineering/testing.md)。

## 隐私保护贯穿设计

网站无需账号，不支持上传简历，也不会在服务器端存储个人申请档案。你收藏、标记为已投递或隐藏的职位，以及上次访问时间，都只保存在浏览器中，不会出现在公共 API 或数据下载中。

网站使用汇总访问统计，但不会向分析服务发送你保存在浏览器中的职位列表或访问时间记录。详情请参阅 [隐私声明](../../PRIVACY.md)。
