## Perché questo progetto?

Trovare un tirocinio o il primo lavoro nel settore tecnologico in Europa non dovrebbe significare passare ore a cercare tra centinaia di annunci sparsi, non aggiornati o poco pertinenti.

**European Tech Opportunities 2027** raccoglie in un'unica directory consultabile **tirocini** e **posizioni New Grad** (per neolaureati e profili entry-level) in tutta Europa, dedicati al ciclo di assunzioni 2027. Le offerte vengono selezionate in base ai criteri di ammissibilità del progetto. La raccolta è programmata ogni tre giorni. I maintainer avviano aggiornamenti aggiuntivi quando compaiono molte nuove offerte o ci sono sviluppi significativi nel mercato del lavoro. Gli aggiornamenti della directory vengono pubblicati in produzione dopo revisione e validazione.

Cerca un'azienda, filtra per Paese o categoria oppure scopri le offerte aggiunte di recente. Puoi anche condividere qualsiasi ricerca tramite un link. Non devi installare nulla né creare un account. **Salva le offerte che ti interessano, tieni traccia delle candidature inviate, nascondi quelle che non fanno per te e scopri le novità dall'ultima visita.** Tutte queste informazioni restano nel tuo browser, senza sincronizzazione tra dispositivi. Contrassegnare un'offerta come «candidatura inviata» serve soltanto a organizzarti: non invia alcuna candidatura.

Vuoi usare i dati anche fuori dal sito? Scarica l'intero elenco delle offerte aperte in **CSV o JSON**, oppure interrogalo tramite l'**API pubblica**, gratuita e di sola lettura.

## Utilizza i dati

Che tu voglia analizzare le offerte in un foglio di calcolo, usarle in un progetto personale o seguirle con un lettore di feed, puoi accedere ai dati senza creare un account.

| Accesso | Ideale per | Cosa offre |
|---|---|---|
| [Directory online](https://techopportunities.eu/) | Cercare e condividere offerte | Ricerca, filtri, ordinamento, paginazione, elenchi salvati nel browser e link agli annunci originali |
| [CSV](https://techopportunities.eu/open-opportunities.csv) | Fogli di calcolo | Dataset completo delle offerte aperte, con testi protetti dall'interpretazione come formule |
| [JSON](https://techopportunities.eu/open-opportunities.json) | Script e analisi | Dataset completo delle offerte aperte in un unico array |
| [API pubblica](https://techopportunities.eu/api/v1/opportunities) | Applicazioni e integrazioni | Risultati JSON filtrabili, ordinabili e paginati, con supporto alla cache |
| [RSS](https://techopportunities.eu/feed.xml) / [Atom](https://techopportunities.eu/atom.xml) | Lettori di feed | Fino a 50 offerte aperte recenti, con filtri facoltativi per tipologia, Paese e categoria |

I file scaricabili includono tutte le offerte aperte, non solo quelle visualizzate nella ricerca corrente. L'API è di sola lettura, non richiede una chiave e permette di filtrare, ordinare e consultare i risultati pagina per pagina.

Per iniziare, leggi la [guida al download dei dati](../users/data/data.md), la [guida all'API](../users/data/api.md) o le [istruzioni per seguire i feed](../users/browsing/directory.md#subscribe-to-new-opportunities).

## La precisione prima della quantità

Quando le informazioni disponibili non bastano a stabilire se un'offerta è pertinente, preferiamo escluderla piuttosto che fare supposizioni. E se un annuncio scompare dai risultati di ricerca, non lo consideriamo automaticamente chiuso.

| Criterio | Cosa verifichiamo |
|---|---|
| **Tipologia di posizione** | Il titolo indica esplicitamente un tirocinio o una posizione New Grad |
| **Livello di esperienza** | Le posizioni con termini associati a ruoli senior o dirigenziali vengono escluse |
| **Ambito tecnologico** | La posizione rientra in una delle categorie tecnologiche configurate |
| **Ciclo di assunzioni / pubblicazione** | L'annuncio indica chiaramente il ciclo 2027 oppure, in assenza di riferimenti a un ciclo incompatibile, presenta prove idonee di pubblicazione dal 1° maggio 2026 in poi |
| **Sede in Europa** | L'annuncio contiene indicazioni chiare che la posizione si trova in Europa |

Per tutti i dettagli, consulta le [regole di classificazione](../maintainers/engineering/classification.md).

## Come funziona

1. Individua annunci pubblici rispettando limiti prestabiliti per le richieste.
2. Verifica ruolo, livello di esperienza, ciclo di assunzioni, data di pubblicazione e sede europea.
3. Memorizza le offerte ammesse e la loro cronologia in SQLite, il database del progetto.
4. Pubblica le offerte aperte sul sito e le rende disponibili tramite API, feed, file scaricabili e anteprima nel README. Questi canali leggono i dati senza modificare lo stato delle offerte né stabilire quali siano ammissibili.

La raccolta dei dati richiede un'autorizzazione esplicita e rispetta limiti fissi per le richieste. Non utilizza account LinkedIn, API private o tecniche per aggirare le protezioni anti-bot. Per approfondire, consulta la [guida all'architettura](../maintainers/engineering/architecture.md) e la [policy di sicurezza](../../SECURITY.md).

## Tecnologie e qualità del codice

Dietro una directory semplice da consultare c'è un progetto open source con un'architettura pensata per essere verificabile e mantenibile.

| Area | Implementazione |
|---|---|
| **Raccolta e classificazione** | Python 3.12+, raccolta asincrona con limiti espliciti, normalizzazione e criteri deterministici di ammissione o esclusione |
| **Persistenza** | SQLite come fonte autorevole per lo stato e la cronologia delle offerte, repository SQLAlchemy e migrazioni Alembic |
| **Applicazione web** | Next.js, React, TypeScript in modalità strict, Tailwind e accesso in sola lettura tramite `node:sqlite` |
| **Dati pubblici** | API versionata, esportazioni CSV/JSON deterministiche, JSON Schema e metadati del dataset con SHA-256 |
| **Test** | Test unitari e d'integrazione con Pytest, percorsi utente con Playwright, controlli di accessibilità con axe, test basati su proprietà, Lighthouse e benchmark di parser e classificatore |
| **Sicurezza e CI** | GitHub Actions, CodeQL, Gitleaks, Dependency Review, OpenSSF Scorecard e validazione di container e documentazione |

I test eseguibili offline controllano l'ammissibilità delle offerte, gli aggiornamenti sicuri del loro stato, la riservatezza degli elenchi nel browser, l'accessibilità, i download e le procedure di ripristino. La [guida ai test](../maintainers/engineering/testing.md) descrive copertura, comandi e limiti noti.

## Privacy fin dalla progettazione

Non servono account, non vengono caricati curriculum e non esistono profili di candidatura conservati sul server. Le offerte che salvi, contrassegni come candidature inviate o nascondi, insieme alla data e all'ora dell'ultima visita, restano nel tuo browser: non vengono incluse nell'API pubblica né nei download.

Il sito utilizza analisi statistiche aggregate, ma non invia agli strumenti di analisi i tuoi elenchi locali o le date delle visite memorizzate nel browser. Per saperne di più, leggi l'[informativa sulla privacy](../../PRIVACY.md).
