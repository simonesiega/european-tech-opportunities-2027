## ¿Por qué este proyecto?

Buscar unas prácticas o un primer empleo en el sector tecnológico europeo no debería implicar revisar cientos de ofertas dispersas, desactualizadas o que no encajan con lo que buscas.

**European Tech Opportunities 2027** reúne en un único directorio las **prácticas** y las **ofertas New Grad** (puestos para recién graduados y perfiles que empiezan su carrera profesional) disponibles en Europa para el ciclo de contratación de 2027. Cada oferta debe cumplir los criterios de selección del proyecto. La recopilación está programada cada tres días. Los responsables del proyecto ejecutan actualizaciones adicionales cuando aparecen muchas ofertas nuevas o hay novedades relevantes en el mercado laboral. Las actualizaciones del directorio se despliegan en producción después de su revisión y validación.

Busca por empresa, filtra por país o categoría y descubre las ofertas incorporadas recientemente. También puedes compartir cualquier búsqueda mediante un enlace. No necesitas instalar nada ni registrarte. **Guarda las ofertas que te interesen, marca aquellas a las que ya has presentado tu candidatura, oculta las que no encajen contigo y descubre qué ofertas se han añadido desde tu última visita.** Tus listas se guardan únicamente en el navegador y no se sincronizan entre dispositivos. Marcar una oferta como «candidatura enviada» es solo una forma de llevar el control: no envía ninguna candidatura.

¿Quieres utilizar los datos fuera de la web? Descarga el conjunto completo de ofertas activas en **CSV o JSON** o consúltalo mediante la **API pública**, gratuita y de solo lectura.

## Utiliza los datos

Para una hoja de cálculo, un proyecto personal o tu lector de noticias favorito: puedes acceder a las ofertas de distintas formas, sin necesidad de crear una cuenta.

| Acceso | Para qué sirve | Qué ofrece |
|---|---|---|
| [Directorio web](https://techopportunities.eu/) | Buscar y compartir oportunidades | Búsqueda, filtros, ordenación, paginación, listas guardadas en el navegador y enlaces a los anuncios originales |
| [CSV](https://techopportunities.eu/open-opportunities.csv) | Hojas de cálculo | Todas las ofertas activas, con texto protegido frente a su interpretación accidental como fórmulas |
| [JSON](https://techopportunities.eu/open-opportunities.json) | Scripts y análisis | Todas las ofertas activas en un único array JSON |
| [API pública](https://techopportunities.eu/api/v1/opportunities) | Aplicaciones e integraciones | Respuestas JSON con filtros, ordenación, paginación y compatibilidad con caché |
| [RSS](https://techopportunities.eu/feed.xml) / [Atom](https://techopportunities.eu/atom.xml) | Lectores de feeds | Hasta 50 ofertas activas recientes, con filtros opcionales por tipo de puesto, país y categoría |

Los archivos descargables incluyen todas las ofertas activas, no solo las que aparecen en tu búsqueda actual. La API, de solo lectura y sin necesidad de clave, permite filtrar y ordenar los resultados, además de consultarlos por páginas.

Para empezar, consulta la [guía de descarga](../users/data/data.md), la [guía de la API](../users/data/api.md) o las [instrucciones para suscribirte a los feeds](../users/browsing/directory.md#subscribe-to-new-opportunities).

## Priorizamos la precisión frente a la cantidad

Si una oferta no presenta información suficientemente clara, preferimos dejarla fuera antes que hacer suposiciones. Del mismo modo, que un anuncio desaparezca de los resultados de búsqueda no significa necesariamente que la vacante se haya cerrado.

| Criterio | Qué verificamos |
|---|---|
| **Tipo de puesto** | El título identifica expresamente unas prácticas o una posición New Grad |
| **Nivel de experiencia** | Se excluyen los puestos que incluyen términos asociados a perfiles sénior o cargos directivos |
| **Área tecnológica** | La oferta corresponde a una de las categorías tecnológicas configuradas |
| **Ciclo de contratación / fecha de publicación** | El anuncio indica claramente el ciclo de 2027 o, si no menciona un ciclo incompatible, aporta pruebas válidas de haberse publicado a partir del 1 de mayo de 2026 |
| **Ubicación europea** | El anuncio incluye información clara que sitúa el puesto en Europa |

Puedes consultar todos los criterios en las [reglas de clasificación](../maintainers/engineering/classification.md).

## Cómo funciona

1. Localiza ofertas públicas respetando límites fijos de solicitudes.
2. Comprueba el tipo de puesto, el nivel de experiencia, el ciclo de contratación, la fecha de publicación y la ubicación en Europa.
3. Almacena las ofertas aceptadas y su historial en SQLite, la base de datos del proyecto.
4. Muestra las ofertas activas en la web, la API, los feeds, los archivos descargables y la vista previa del README. Todas estas interfaces son de solo lectura: no modifican el estado de las ofertas ni determinan cuáles cumplen los requisitos.

La recopilación de datos requiere autorización expresa y respeta límites de solicitudes predefinidos. No utiliza cuentas de LinkedIn, API privadas ni métodos para eludir los sistemas antibot. Si quieres conocer el funcionamiento interno, empieza por la [guía de arquitectura](../maintainers/engineering/architecture.md) y la [política de seguridad](../../SECURITY.md).

## Ingeniería

Detrás de la sencillez del directorio hay un proyecto de código abierto. Estas son sus principales tecnologías y componentes:

| Área | Implementación |
|---|---|
| **Recopilación y clasificación** | Python 3.12+, recopilación asíncrona con límites definidos, normalización y decisiones deterministas de aceptación o rechazo |
| **Persistencia** | SQLite como fuente de referencia del estado y ciclo de vida de las ofertas, capa de repositorio con SQLAlchemy y migraciones con Alembic |
| **Aplicación web** | Next.js, React, TypeScript en modo estricto, Tailwind y acceso de solo lectura a través de `node:sqlite` |
| **Datos públicos** | API versionada, exportaciones CSV/JSON deterministas, JSON Schema y metadatos del conjunto de datos con SHA-256 |
| **Pruebas** | Pruebas unitarias y de integración con Pytest, recorridos de usuario con Playwright, comprobaciones de accesibilidad con axe, pruebas basadas en propiedades, Lighthouse y benchmarks del parser y clasificador |
| **Seguridad e integración continua** | GitHub Actions, CodeQL, Gitleaks, Dependency Review, OpenSSF Scorecard y validación de contenedores y documentación |

Las pruebas que se ejecutan sin conexión verifican los criterios de selección, la seguridad de los cambios de estado, la privacidad de las listas locales, la accesibilidad, las descargas y los mecanismos de recuperación. La [guía de pruebas](../maintainers/engineering/testing.md) recoge la cobertura, los comandos y las limitaciones conocidas.

## Privacidad desde el diseño

No hay cuentas de usuario, ni se suben currículums ni se almacenan perfiles de candidatura en el servidor. Las ofertas que guardas, marcas como «candidatura enviada» u ocultas, junto con la fecha de tu última visita, permanecen en tu navegador. Esa información no se incluye en la API pública ni en los archivos descargables.

La web utiliza estadísticas de uso agregadas, pero no envía a las herramientas de análisis tus listas locales ni las marcas de tiempo de tus visitas. Encontrarás más detalles en el [aviso de privacidad](../../PRIVACY.md).
